# clipfont

Clip identifiers and font tokens for idempotent workflows.

**Site:** https://theworker02.github.io/clipfont/

## Install / run

```bash
git clone https://github.com/theworker02/clipfont.git
cd clipfont
node src/cli.js
node --test
```
